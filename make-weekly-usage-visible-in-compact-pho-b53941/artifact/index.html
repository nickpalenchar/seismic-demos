Phone usage pills show Session and Week

Three harnesses report limits, so the phone uses compact pills. Each pill now shows every limit with a one-letter name (S = Session, W = Week) and a plain percentage.

  • Claude: Session 83 % above Week 27 %. Both are visible.
  • Codex reports only Session (12 %), so its pill shows only S.
  • Antigravity: S 40 %, W 61 %.

Progress bars stay in the popover on tap. The pills scroll sideways as before.
